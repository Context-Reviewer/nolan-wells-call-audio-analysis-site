**Version:** 1.0

## Review status

- Reviewer: not assigned

Until this checklist is completed, speech conclusions remain provisional
examiner assessments.

## Materials to review

- [ ] Case scope
- [ ] Evidence manifest and hashes
- [ ] Source and working audio
- [ ] Standard operating procedure
- [ ] Observation records
- [ ] Processing presets and settings
- [ ] Validation report
- [ ] Model-output provenance
- [ ] Draft report
- [ ] Public website wording

## Technical checks

- [ ] Source limitation is accurately stated.
- [ ] Hashes match the files reviewed.
- [ ] Candidate boundaries are justified.
- [ ] Channel labels and routing are correct.
- [ ] Raw audio is compared with every processed conclusion.
- [ ] Processing settings are fully disclosed.
- [ ] No generated audio is represented as evidence.
- [ ] Model output is labeled exploratory.
- [ ] Contrary and unintelligible results are retained.
- [ ] Confidence categories follow the adopted framework.
- [ ] Conclusions do not exceed the examined derivative source.
- [ ] Alternative interpretations are fairly represented.
- [ ] Website controls reproduce the described settings.
- [ ] Validation limitations are disclosed.

## Reviewer disposition

- [ ] Accepted without substantive change
- [ ] Accepted with listed corrections
- [ ] Not accepted
