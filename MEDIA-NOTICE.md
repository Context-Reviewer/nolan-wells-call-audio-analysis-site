# Media Notice

This repository contains audio derived from a publicly available YouTube upload of a
recording described as an MDMR public-records release. The legal status of the native
recording and the uploader's audiovisual publication may differ by jurisdiction and use.

Before making the repository public, review whether publishing the complete source and
full-length derived channels is appropriate. A lower-risk public version would contain:

- scripts and methodology;
- hashes and sanitized metadata;
- spectrograms;
- short, necessary analytical excerpts;
- links or identifiers for the publicly available source rather than a full media copy.

added later should clearly apply only to original code and documentation unless the
